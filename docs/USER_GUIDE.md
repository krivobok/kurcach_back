# Руководство пользователя

Это руководство описывает обычный клиентский сценарий работы с сайтом.

## Запуск сайта

```powershell
python run.py
```

Откройте:

```text
http://127.0.0.1:5000
```

## Регистрация клиента

1. На главной странице введите логин.
2. Введите пароль.
3. В поле `Тип аккаунта` выберите `Клиент`.
4. Нажмите `Регистрация`.

После регистрации вы сразу входите в аккаунт и можете играть.

## Вход

1. Введите логин и пароль.
2. Нажмите `Войти`.

Если аккаунт заблокирован администратором, вход будет запрещён.

## Игра с компьютером

1. Войдите в аккаунт.
2. Нажмите `Играть с компьютером`.
3. Нажимайте на свободные клетки поля.
4. После вашего хода сервер автоматически сделает ход компьютера.

Дополнительные кнопки:

- `Подсказка` - покажет лучший ход.
- `Сдаться` - завершит партию поражением.
- `Реванш` - начнёт новую партию после завершения.

В блоке `Серверный анализ позиции` сайт показывает:

- рекомендацию backend-сервиса;
- уровень риска позиции;
- лучший ход по оценке сервера;
- количество свободных клеток и процент заполнения поля.

## Игра с другим пользователем

Первый игрок:

1. Входит в аккаунт.
2. Нажимает `Комната для друга`.
3. Ждёт второго игрока.

Второй игрок:

1. Входит в аккаунт в другом браузере или другом окне.
2. Находит комнату в списке `Комнаты`.
3. Нажимает `Играть`.

После входа второго игрока партия начнётся автоматически.

## Почему играть можно без Postman

Основной пользовательский сценарий вынесен в обычные HTML-формы:

- регистрация и вход выполняются на главной странице;
- комната создаётся кнопкой;
- ход делается нажатием по свободной клетке;
- подсказка, сдача и реванш доступны отдельными кнопками.

Postman и Swagger нужны для проверки API и демонстрации серверной части, но для игры через сайт они не требуются.

## Рейтинг

Рейтинг доступен:

```text
http://127.0.0.1:5000/leaderboard
```

Рейтинг меняется после завершения партий:

- победа увеличивает рейтинг;
- поражение уменьшает рейтинг;
- ничья даёт небольшой прирост.

## Комнаты, закрытые администратором

Если администратор закрыл комнату:

- новые игроки не смогут войти;
- ходы больше не принимаются;
- реванш недоступен;
- в интерфейсе появится сообщение об ошибке.

Если администратор удалил комнату:

- ссылка на комнату возвращает `404`;
- связанная игра и история ходов удаляются.
