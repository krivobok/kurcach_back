# Руководство администратора

Администратор управляет пользователями, комнатами и журналом действий.

## Создание администратора

Откройте:

```text
http://127.0.0.1:5000/admin
```

Введите:

- логин;
- пароль;
- код администратора.

Код по умолчанию:

```text
admin123
```

Нажмите `Создать админа`.

Для изменения кода перед запуском сервера:

```powershell
$env:ADMIN_REGISTRATION_CODE="my-secret-code"
python run.py
```

## Вход в админ-панель

1. Откройте `/admin`.
2. Введите логин и пароль администратора.
3. Нажмите `Войти`.

Если обычный клиент попытается открыть админские данные, backend вернёт ошибку `403`.

## Возможности администратора

### Сводка

В верхней части панели отображаются:

- количество пользователей;
- количество комнат;
- количество активных игр;
- количество завершённых игр.

### Пользователи

Для каждого пользователя доступны действия:

- `Сделать администратором`;
- `Сделать клиентом`;
- `Заблокировать`;
- `Разблокировать`;
- `Отозвать токены`;
- `Удалить`.

Ограничения безопасности:

- администратор не может заблокировать самого себя;
- администратор не может удалить самого себя;
- администратор не может снять права администратора с самого себя.

### Блокировка пользователя

При блокировке:

- статус пользователя становится `banned`;
- все активные токены пользователя отзываются;
- пользователь больше не может войти;
- старые запросы с его токеном начинают возвращать `401`.

### Комнаты

Для комнат доступны действия:

- `Завершить`;
- `Закрыть`;
- `Удалить комнату`.

Разница:

- `Завершить` переводит комнату в статус `finished`. Если была активная игра, она завершается.
- `Закрыть` переводит комнату в статус `closed`. Новые входы, ходы и реванши запрещаются.
- `Удалить комнату` физически удаляет комнату, связанную игру, ходы и чат. Старые ссылки возвращают `404`.

### Журнал действий

В журнал попадают:

- регистрация;
- вход и выход;
- создание комнат;
- вход в комнаты;
- сдача партии;
- реванш;
- действия администратора с пользователями;
- действия администратора с комнатами.

## Админские REST endpoints

Основные endpoints:

- `GET /api/admin/dashboard`
- `GET /api/admin/users`
- `GET /api/admin/users/{user_id}`
- `PATCH /api/admin/users/{user_id}/role`
- `PATCH /api/admin/users/{user_id}/status`
- `POST /api/admin/users/{user_id}/tokens/revoke`
- `DELETE /api/admin/users/{user_id}`
- `GET /api/admin/rooms`
- `PATCH /api/admin/rooms/{room_id}/status`
- `DELETE /api/admin/rooms/{room_id}`
- `GET /api/admin/audit`

Полное описание доступно в Swagger:

```text
http://127.0.0.1:5000/swagger
```
